

# Gordon Lightfoot Project Website — Tasks

This document organizes implementation into broad phases.

The intent is:
- incremental visible progress
- early establishment of tone and structure
- lightweight architecture
- gradual refinement rather than overbuilding

---

# Phase 1 — Foundation & Visual Direction

Goal:
Establish the overall visual language, layout structure, typography, spacing, and atmospheric direction of the site.

Tasks:
- Set up project structure
- Create semantic page layout
- Establish typography system
- Establish color palette
- Implement spacing/layout rhythm
- Create hero section
- Add placeholder navigation
- Add placeholder sections for:
  - Featured Video
  - About
  - Musicians
  - Performances
  - Contact
- Establish responsive layout foundations
- Implement restrained motion system
  - fades
  - hover states
  - transitions

Deliverables:
- coherent visual identity
- functional page skeleton
- strong first impression
- responsive foundation

Important notes:
- prioritize atmosphere over features
- avoid premature complexity
- use placeholder content aggressively if needed
- focus on elegance and restraint

---

# Phase 2 — Featured Video Experience

Goal:
Build the central media experience of the site.

Tasks:
- Implement primary featured video player
- Add selectable performance list/carousel
- Implement video switching behavior
- Add metadata display:
  - song title
  - vocalist
  - optional venue/date
- Ensure minimal embedded-player UI
- Tune spacing and visual hierarchy
- Ensure clean desktop and mobile behavior

Deliverables:
- polished curated video experience
- scalable structure for additional performances
- visually restrained media section

Important notes:
- avoid clutter
- avoid multiple simultaneous large embeds
- keep transitions subtle
- preserve calm visual pacing

---

# Phase 3 — Musician & Ensemble Presentation

Goal:
Introduce the musicians in a way that feels personal, musical, and human without becoming self-promotional.

Tasks:
- Build musician profile layout
- Support portrait-oriented headshots
- Create responsive musician section behavior
- Add:
  - name
  - instruments
  - short bio
  - Lightfoot reflection
- Add compact featured audio component
- Support missing/incomplete media gracefully
- Tune layout consistency despite uneven assets

Deliverables:
- visually cohesive ensemble presentation
- lightweight audio integration
- clear representation of multiple lead vocalists

Important notes:
- avoid corporate team-page aesthetics
- emphasize musical connection over résumé language
- keep audio UI visually restrained

---

# Phase 4 — Performances, Booking & Supporting Pages

Goal:
Add lightweight professional infrastructure without overbuilding.

Tasks:
- Build Upcoming & Recent Performances section
- Create simple performance-entry structure
- Add booking/contact section
- Implement email interaction behavior
- Create placeholder EPK page
- Create placeholder Stage Plot page
- Add stand-in technical/media content where necessary
- Ensure navigation between pages feels cohesive

Deliverables:
- functioning booking/contact flow
- lightweight professional materials
- scalable event structure

Important notes:
- keep performance system intentionally modest
- avoid empty-feeling calendar systems
- prioritize clarity and professionalism

---

# Phase 5 — Refinement, Polish & Content Integration

Goal:
Refine the overall experience into a cohesive finished site.

Tasks:
- Replace placeholder content with real content
- Refine typography and spacing
- Tune responsive/mobile behavior
- Improve accessibility
- Optimize image/media loading
- Refine transitions and motion pacing
- Test embedded media behavior
- Add favicon/logo assets
- Finalize footer/details
- Review visual consistency across all sections
- Remove visual clutter
- Tune atmosphere and pacing

Deliverables:
- polished production-ready site
- cohesive visual identity
- smooth responsive experience
- maintainable lightweight architecture

Important notes:
- restraint is a feature
- remove unnecessary elements aggressively
- prioritize clarity, warmth, and musical focus
- preserve the handcrafted feeling of the site

---

# Guiding Principle

At every phase, the site should move toward:

A thoughtful ensemble sharing songs they genuinely love.
