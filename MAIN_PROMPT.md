# Main Prompt

Read:
- VISION.md
- SPEC.md
- TASKS.md

Then work through the project one phase at a time.

For each phase:

1. Read the phase carefully.
2. Briefly explain:
   - what the phase is trying to accomplish
   - what you are going to implement
   - any important architectural or design decisions
3. Implement the work.
4. Summarize what you changed.
5. Clearly describe what should now be visible in the app/site/codebase so the implementation can be verified.
6. End by asking:

"Ask questions, give feedback, or just say OK to move on."

Additional guidance:
- Preserve the restrained, warm, music-centered tone described in VISION.md.
- Prioritize elegance and clarity over feature quantity.
- Keep the implementation lightweight and maintainable.
- Avoid overengineering.
- Use placeholder content freely when real assets/content are not yet available.
- Make progress incrementally and visibly.
- Do not begin the next phase until feedback/approval is given.
